# NGINX Administration

Solution to the NGINX Administration exercise at https://github.com/arturomorarioja/nginx_admin_start.

It contains a Docker container with three ASP.NET applications and a working NGINX installation fulfilling all exercise requirements.

## Start

```bash
docker compose up -d --build
```

The web server should be available at `http://localhost:8080/`.

## Tools
NGINX / .NET/ASP.NET Core 10.0 / Water.css / HTML5
